ข้อกำหนด 12 ข้อ
Q1 (10): เชื่อมฉากและปุ่มให้ครบตามรูปหน้า 9 ใช้ UI Text บอกชื่อฉาก
    Main Menu -> Stage Selection -> Stage 1 หรือ Stage 2
    Main Menu -> Options แบบ Additive; ปุ่ม OK ปิด Options กลับเมนู
    Stage Selection ปุ่ม Back -> Main Menu
    Stage 1/2 ปุ่ม Back -> Stage Selection ตามลูกศรในภาพ
    Stage 1/2 ส่งผลไป Win หรือ Game Over และแสดงคะแนน
    Win/Game Over มี Back To Main Menu; Game Over มี Try Again
    Main Menu มี Exit
    ภาพมี Credits พร้อมชื่อ/รหัสและ Back แต่ไม่เห็นเส้นเชื่อมหรือปุ่มเข้า Credits ชัดเจน
    ควรยืนยันทางเข้า Credits และปลายทาง Try Again; ข้อเสนอคือ Credits เข้าจากเมนู และ Try Again เริ่มด่านล่าสุด
    ข้อความหน้า 6 กล่าวถึงกลับ Main Menu ในหัวข้อแพ้ แต่ภาพมี Game Over คั่น จึงควรยืนยันหากต้องตรงทุกเส้น
Q2 (5): Stage 1 ใช้ Capsule Player ตามบทเรียน ไม่ใช่แทนด้วย Humanoid โดยไม่ตั้งค่าตามโจทย์
Q3 (5): Stage 1 สร้างด้วย ProBuilder ทางแคบและกว้าง มีจุดตกแล้วแพ้ ใช้ Prefab วางไอเท็มทั่วแผนที่
Q4 (5): ไอเท็ม 4 ชนิด: เวลา +3 วินาที, เวลา -5 วินาที, คะแนน +500, คะแนน -500
    Stage 1 รับผลเมื่อชน/เข้า Trigger; แยกประเภทด้วย component หรือ tag ได้
    ต้องกรอกชื่อ Prefab ที่ใช้จริงในแบบตอบ
Q5 (10): HUD คะแนนและเวลา นับถอยหลังเริ่ม 30 วินาทีที่มุมซ้ายบน
    ข้อความระบุเกมจบเมื่อหมดเวลา; คะแนนมากกว่า 10,000 จึงชนะ; ตกจากทางเดินแพ้
    โจทย์ระบุแพ้เมื่อไม่ถึง 10,000 จึงเว้นกรณีเท่ากับ 10,000 ต้องสอบถามผู้สอน
    ข้อเสนอหากยึดคำว่า “มากกว่า”: เวลาเป็น 0 แล้ว score > 10000 ชนะ นอกนั้นแพ้
    ไม่ควรชนะทันทีที่แตะเป้าคะแนน หากยึดข้อที่บอกจบเมื่อหมดเวลา
    ต้องมีไอเท็ม +500 อย่างน้อย 21 ชิ้นที่เก็บได้ และเผื่อชิ้นชดเชยคะแนนติดลบ

Q8 (10): Stage 2 ไอเท็ม 4 ชนิดเหมือน Stage 1 แต่เก็บผ่าน Interaction แทนเดินชนแล้วเก็บทันที
    ตัวอย่างวิธีทำ: เข้าใกล้แสดง prompt กด E แล้วจึงรับผลและเก็บไอเท็ม
    Stage 2 ใช้เงื่อนไขแพ้/ชนะและเวลาแบบ Stage 1
Q9 (5): Options ปรับระดับเสียง BGM และ SFX แยกกันได้และมีผลจริง

เงื่อนไขส่งงานที่ PDF เน้น
- ส่งผ่าน Git repository ใหม่ที่เป็น public ตาม URL ที่ระบุเท่านั้น
- commit และ push อย่างน้อยวันละ 1 ครั้งตลอดช่วงสอบ; ใช้ข้อความ commit สื่อความหมาย
- แนบ screenshot Git history ที่เห็นเวลาและรายการ commit
- โค้ดที่พัฒนาขึ้นอยู่ใน namespace ชื่อภาษาอังกฤษของนักศึกษา
- เขียนชื่อ/รหัสทุกหน้า และกรอกส่วนหลักฐานตามที่กำหนด
- ทำบันทึกความคืบหน้าจริง ไม่มีการย้อนหลังวันที่ commit
